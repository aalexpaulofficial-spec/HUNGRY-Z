# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Older versions | No |

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal data or unpatched vulnerability reports in a public issue. Use GitHub's **Report a vulnerability** option on this repository's Security tab to send a private report to the maintainers. If that option is unavailable, contact **hungryofficialx@gmail.com** with a concise description and safe reproduction steps.

Do not include live credentials, payment data or customer records in a report. The maintainers will acknowledge reports as soon as practical and coordinate a fix and disclosure timeline with the reporter.
